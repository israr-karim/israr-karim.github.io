Collaborative side project / Applied AI

HireBetter

Co-developed with MD. Sakib Khan (opens in a new tab), HireBetter analyzes recorded interviews using video, audio, and transcripts to surface potential integrity concerns for human review.

A Next.js frontend and NestJS API handle uploads and analysis jobs. S3 stores artifacts, while SQS queues work for Python analysis workers on ECS. The pipeline uses OpenCV and ffmpeg for media processing, then combines extracted signals, transcription, and LLM-assisted judging into reports linked to supporting evidence.

My contributions focus on the analysis worker, signal extraction, judging logic, report generation, and evaluation with attention to false positives.

  • Next.js
  • NestJS
  • Python

06 / Research direction

Questions I want to investigate.

My graduate interests connect what I have built so far with the problems I want to study more deeply.

  1. 01

    Video & multimodal learning

    How can models learn temporal structure in video and connect motion with language, rather than rely on isolated visual cues?

    Starting point: sign-language video experiments and interview analysis using video, audio, and transcripts.

  2. 02

    Reliable evaluation & human feedback

    How should we evaluate a system when labels are imperfect, reviewers disagree, and false positives have a real cost?

    Starting point: RLHF consensus workflows, enterprise data quality, and evidence-linked interview review.

  3. 03

    Perception for robotics

    How can visual and sensor representations support useful decisions when conditions change and computation is constrained?

    A direction for graduate research, building on my interest in vision and experience with embedded sensing and robotics prototypes.

Application interest Healthcare and assistive technology are areas I would like to explore, connecting my interest in medical research with systems that can help people.
