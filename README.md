# Kazi Israrul Karim — Portfolio

**Live website:** https://israr-karim.github.io/

A personal portfolio covering enterprise data engineering, applied AI, full-stack systems, selected projects, and graduate research interests.

## Stack

Semantic HTML, responsive CSS, and inline SVG illustrations. There are no runtime packages, external font services, JavaScript frameworks, or build steps. Native HTML disclosures provide the additional-projects and coursework sections.

## Files

- `index.html` — content, metadata, and illustrations.
- `styles.css` — layout, responsive styles, and accessibility preferences.
- `favicon.svg` — site icon.
- `.nojekyll` — publishes the static files directly through GitHub Pages.

## Preview locally

From this folder, run:

```sh
python3 -m http.server 8000
```

Open http://localhost:8000. Stop the server with Ctrl+C. You can also open `index.html` directly in a browser.

## Edit and publish

Edit `index.html` for content and `styles.css` for layout. Push changes to `main` to update GitHub Pages. The publishing source is `main` with the repository root (`/`) as the source folder.

All asset paths are relative. If the domain changes, update the canonical and Open Graph URL tags in `index.html`.
